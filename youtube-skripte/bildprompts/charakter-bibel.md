# Character bible — all videos

This is the master list of every recurring character and element. Each one has a fixed description that is pasted word for word into every scene prompt where it appears, plus a reference sheet prompt. The per-video prompt files contain the same blocks, so you can work from either.

## Rules that apply to every image

- No text, letters, numbers, captions, labels, logos or watermarks anywhere in the image. Everyone wears modest clothing. Keep every character exactly as described: same face, hair, skin tone, body and clothing in every image.
- Every prompt asks for a widescreen 16:9 landscape image.
- No depiction of the Prophet Muhammad or of his companions — only architecture, landscapes or objects.
- Real people are never named in a prompt (Copilot refuses or invents a different face). Characters based on real people have a fictional, fixed look; real people from recent decades and all living people are shown only from behind, in profile in shadow, as silhouettes or as hands.
- No blood, no gore, no swastikas or other extremist symbols, no brand logos.

## How consistency is guaranteed

1. **Same words every time.** The description of a character is generated once and copied unchanged into every prompt. Copilot gets the identical face, hair and clothing details each time.
2. **Signature details.** Every character has 2–3 features nobody else in that video has (a color, a garment, an object), so viewers recognize them even when Copilot varies the face slightly.
3. **Reference sheet first.** Generate the sheet, save it, and attach it to the chat whenever a face drifts.
4. **One chat per video.** Copilot keeps the earlier images of the conversation in mind.
