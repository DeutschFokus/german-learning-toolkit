# Ötzi long video — picture list (16:9)

**How to use:** copy each box into your image tool, one at a time. Every box is complete. Midjourney: add ` --ar 16:9 --style raw` at the end. ChatGPT / Gemini: paste as is.

**Rules for every picture:** wide 16:9 (landscape), as big as possible, no text, no watermark, **no faces** (people only from behind, as silhouettes, or very far away). Send them to me in the chat with the number in the name or in your message (for example "07").

If a picture looks wrong or shows a face, make it again.

**Pace:** a new picture every 3–5 seconds, about 3 seconds in the first minute. That needs **90 pictures + the thumbnail** (01–42, 10a/10b, then 43–89 further down). I also cut some pictures twice (wide, then a close detail), so every shot is fresh.

**Order:** please make them chapter by chapter and send each batch when it's done. **Start with the first-minute set:** 01, 02, 03, 04, 06, 14, 20, 22, 25, 26, 27, 31, 41, 43–48 and T1. With those I can build and show you the opening first.
