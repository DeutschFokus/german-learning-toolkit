# German Learning Toolkit

Free and open-source German learning resources for learners, teachers, and developers.

This project provides structured materials for learning German from A1 to advanced levels, including:

- Grammar explanations
- Vocabulary
- Practical exercises
- Answer keys
- Reading materials
- Real-world German examples
- Reusable language-learning data

## Current Content

### Learner Guide — *Your German Journey*
- A 52-page roadmap from A0 to C2 for learners with 20–30 minutes a day: the method, level-by-level plans, pronunciation rules, a resource directory with QR codes and printable templates
- [Download the PDF](guide/Your-German-Journey.pdf) · [Source and build instructions](guide/README.md)

### A1 Grammar
- German articles
- Present tense
- Word order
- Accusative case
- Dative case

- A1 vocabulary dataset in JSON format
