# German Learning Toolkit

Free and open-source German learning resources for learners, teachers, and developers.

This project provides structured materials for learning German from A1 to advanced levels, including:

- Grammar explanations
- Vocabulary
- Practical exercises
- Answer keys
- Reading materials
- Real-world German examples
- Reusable language-learning data

## Current Content

### A1 Grammar
- German articles
- Present tense
- Word order
- Accusative case
- Dative case

### B1 Book (in German)
- [100 B1-Fehler – Korrigiere sie vor B2](B1/buch/README.md): 100 recurring intermediate-learner mistakes with corrections, one rule each, examples, mini-tests and B2 upgrades, plus a placement test, a final test and reference tables

### Structured Data
- A1 vocabulary dataset in CSV format
- A1 vocabulary dataset in JSON format
- English translations
- Part-of-speech labels
- CEFR metadata
- Example sentences
