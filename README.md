# German Learning Toolkit

Free and open-source German learning resources for learners, teachers, and developers.

This project provides structured materials for learning German from A1 to advanced levels, including:

- Grammar explanations
- Vocabulary
- Practical exercises
- Answer keys
- Reading materials
- Real-world German examples
- Reusable language-learning data

## Current Content

### A1
- Grammar
  - German articles

## Goal

The goal of this project is to build a clear, practical, and reusable German-learning resource that can be used by individual learners, teachers, educational projects, and language-learning tools.
