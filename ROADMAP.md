# Roadmap

The German Learning Toolkit is being developed as a free and reusable collection of German-learning resources.

## Phase 1 — Foundation

- [x] Create the repository
- [x] Add the first A1 grammar resource
- [x] Create a project README
- [x] Add contribution guidelines
- [ ] Add more A1 grammar topics
- [ ] Add A1 vocabulary resources
- [ ] Add exercises and answer keys

## Phase 2 — Expand the Learning Content

- [ ] Add A2 materials
- [ ] Add B1 materials
- [ ] Add B2 materials
- [ ] Add reading texts and short stories
- [ ] Add topic-based vocabulary collections
- [ ] Add practical example sentences

## Phase 3 — Structured Data

- [ ] Create machine-readable vocabulary datasets
- [ ] Provide vocabulary in CSV format
- [ ] Provide vocabulary in JSON format
- [ ] Add CEFR-level metadata
- [ ] Make the data reusable for educational applications

## Phase 4 — Interactive Tools

- [ ] German article trainer
- [ ] German case trainer
- [ ] Word-order exercises
- [ ] Vocabulary quizzes
- [ ] Sentence-analysis tools

## Long-Term Goal

The long-term goal is to create an open educational resource that can be reused by German learners, teachers, developers, language-learning applications, and other educational projects.
