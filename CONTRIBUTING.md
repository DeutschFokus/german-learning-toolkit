# Contributing

Thank you for your interest in contributing to the German Learning Toolkit.

Contributions are welcome from German learners, teachers, native speakers, developers, and anyone interested in language education.

## Ways to Contribute

You can help by:

- correcting mistakes
- improving grammar explanations
- adding example sentences
- creating exercises
- adding vocabulary
- improving existing learning materials
- suggesting new topics
- contributing useful tools or structured language data

## Content Guidelines

Please make sure contributions are:

- accurate
- clear and easy to understand
- useful for German learners
- organized by the appropriate CEFR level when possible
- written in natural German and clear English

## Corrections

If you find an error, you can open an issue or submit a pull request.

## Pull Requests

Please describe clearly what you changed and why the change improves the project.

Thank you for helping make German-learning resources more accessible and useful.
