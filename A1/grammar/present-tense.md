# German Present Tense – A1

The present tense in German is used to talk about things that happen now, regularly, or generally.

## Regular Verbs

Most regular German verbs follow a predictable pattern.

Example verb: `lernen` — to learn

| Pronoun | Form |
|---|---|
| ich | lerne |
| du | lernst |
| er / sie / es | lernt |
| wir | lernen |
| ihr | lernt |
| sie / Sie | lernen |

## Basic Pattern

Remove `-en` from the infinitive and add the correct ending:

- ich → `-e`
- du → `-st`
- er / sie / es → `-t`
- wir → `-en`
- ihr → `-t`
- sie / Sie → `-en`

## Examples

- Ich lerne Deutsch.
- Du arbeitest heute.
- Er wohnt in Berlin.
- Wir spielen Fußball.
- Ihr macht die Hausaufgaben.
- Sie lernen zusammen.

## Practice

Complete the sentences with the correct verb form.

1. Ich ___ Deutsch. `(lernen)`
2. Du ___ in München. `(wohnen)`
3. Er ___ heute. `(arbeiten)`
4. Wir ___ Fußball. `(spielen)`
5. Ihr ___ Kaffee. `(machen)`

## Answers

1. lerne
2. wohnst
3. arbeitet
4. spielen
5. macht
